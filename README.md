# Talks assets

文涛（Ding / 石骆）的公开演讲资料，供 [Ding's Blog](https://wynterding.com/talks) 使用。

每次分享发布为独立的 GitHub Release，包含原始 PDF、逐页 WebP 预览、社交分享封面和 `talk.json` 资料清单。文件放在 Releases 附件中，仓库 Git 历史只保留这份说明。

版本标签格式为 `talk-<slug>-v<revision>`。已经发布的版本保持不变，更新资料时发布下一版本。

请在 [Releases](https://github.com/WynterDing/talks-assets/releases) 中浏览和下载资料。
